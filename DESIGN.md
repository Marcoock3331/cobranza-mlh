# MLH Cobranza - Design System

Este documento define las directrices de diseño y la configuración base que debe utilizarse en todos los componentes del proyecto **MLH Cobranza**.

## Paleta de Colores (Tailwind CSS)

Se debe utilizar **estrictamente** esta paleta de colores en todos los componentes generados para mantener la consistencia visual:

*   **Primary (Azul Marino Oscuro):** `#0a192f`
*   **Secondary (Amarillo Brillante):** `#ffd700`
*   **Success (Verde Vibrante):** `#10b981`
*   **Danger (Rojo):** `#ef4444`
*   **Background (Gris Claro):** `#f4f6f8`
*   **Surface (Blanco Puro):** `#ffffff`

## Tipografía

*   **Tipografía Base:** Sans-serif limpia. Se debe favorecer la legibilidad y un diseño moderno.
